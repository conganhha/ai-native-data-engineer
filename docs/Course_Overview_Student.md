# Course overview – student-safe

Chuỗi 8 buổi: Business Requirement → ERD → PostgreSQL OLTP → SQL Analytics → Sales Data Mart → Python File/API Ingestion → Data Quality → Automated Daily Pipeline.

Nguyên tắc xuyên suốt: **không sửa RAW**, mọi transformation/validation phải có thể tái chạy, và kết quả phải đối soát được. Thiết kế ERD/Data Mart cụ thể là sản phẩm học tập của Buổi 1 và Buổi 4 nên không được cung cấp sẵn trong tài liệu này.
