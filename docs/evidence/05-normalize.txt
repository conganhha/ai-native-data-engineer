Quy tac chuan hoa ap dung (theo thu tu):
  1. Ten cot  : strip() + lower()                        -> chuan hoa header
  2. String   : strip() khoang trang dau/cuoi            -> object/string
  3. Email    : lower()                                  -> cot email
  4. Enum     : lower()  (status, payment_status, payment_method, channel)
  5. Numeric  : pd.to_numeric(errors='coerce')           -> float64
  6. Datetime : pd.to_datetime(errors='coerce', utc=True)-> datetime64[ns, UTC]

Chu y: normalize() tra ve ban COPY (out = df.copy()), khong sua file RAW/source.
