# Mini Project – Automated E-commerce Data Ingestion Pipeline

## Yêu cầu
1. Tạo OLTP database từ script.
2. Nạp seed data và chạy bộ SQL Analytics.
3. Tạo Sales Data Mart.
4. Ingest daily file + REST API.
5. Validate, tách reject, upsert incremental, ghi audit.
6. Chạy pipeline hai lần, chứng minh không duplicate.
7. Refresh Data Mart và so sánh KPI before/after.
8. Demo 5–7 phút: kiến trúc, một lỗi, cách xử lý, KPI thay đổi.

## Rubric
- OLTP/Data Mart: 20%
- SQL Analytics: 15%
- Python ingestion: 20%
- Data Quality: 20%
- Idempotency/automation/logging: 15%
- Demo/README: 10%
